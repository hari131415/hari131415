### 02 — Smart Home Support Agent with GenAIOps

A retrieval-augmented generation support agent built using public smart home device manuals and Vertex AI Gemini.

- Knowledge retrieval and grounded troubleshooting responses.
- Tool calling for device status lookup.
- Agent tracing and token-cost tracking in BigQuery.
- Guardrails and human escalation workflows.
- Automated evaluation suite covering 150 support questions.
- CI quality gates for prompt and retrieval changes.
